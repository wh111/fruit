贴纸打印需要什么硬件？

            
    
              
  1. 热敏标签打印机（推荐）：汉印 / 佳博 / 芯烨，USB 接电脑，约 200–500 元
    2. 
              
  2. 标签纸：40×30mm 或 50×30mm 热敏不干胶（防水更好）
    3. 
              
  3. 电脑打开本管理端 → 订单「打印标签」→ 选打印机即可贴杯
    4. 
            

            
也可买蓝牙标签机（精臣/汉印）用手机打；或买云打印机实现支付后自动出纸。
