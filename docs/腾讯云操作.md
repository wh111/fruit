# 腾讯云部署 · 四季果先（一步步）

目标：服务器能打开管理端、小程序能请求 API、数据进 MySQL、支付回调能打到你的域名。

---

## 0. 准备账号

1. 打开 [云.tencent.com](https://cloud.tencent.com/) 注册/实名认证  
2. 建议先充值少量余额，或用新用户代金券  
3. 控制台右上角确认已实名（未实名很多产品开不了）

---

## 1. 买云服务器 CVM（必做）

1. 控制台 → **云服务器 CVM** → 新建  
2. 推荐配置（够用）：  
   - 地域：离你门店近的（如上海 / 广州）  
   - 机型：2核 4GB  
   - 镜像：**Ubuntu Server 22.04 LTS**  
   - 硬盘：系统盘 40GB+  
   - 网络：分配**公网 IP**，带宽 3～5Mbps 即可  
3. 设置 root/ubuntu 登录密码或 SSH 密钥（务必自己记住）  
4. 创建后在实例列表记下：**公网 IP**

### 安全组（很重要）

实例 → 安全组 → 入站规则放行：

| 端口 | 用途 |
|------|------|
| 22 | SSH 登录 |
| 80 | HTTP |
| 443 | HTTPS（支付回调、小程序） |
| 3000 | 临时调试用，上线后可关掉，只留 80/443 |

---

## 2. 买云数据库 MySQL（必做）

1. 控制台 → **云数据库 MySQL** 或 **TDSQL-C MySQL** → 新建  
2. 选与 CVM **同一地域、同一 VPC**（否则连不上内网）  
3. 规格：1核1G / 最小版即可起步  
4. 设置 root 密码，创建库  

创建后：

1. 进入实例 → **数据库管理** → 新建库：`sijiguoxian` 字符集 `utf8mb4`  
2. **账号管理** → 新建账号（如 `sijiguoxian`），授权该库读写  
3. **安全组 / 网络**：允许你的 CVM 内网访问 3306  
4. 记下：**内网地址**、端口（一般 3306）、账号、密码  

在 CVM 上导入表结构（把项目传到服务器后）：

```bash
# 先装客户端
sudo apt update && sudo apt install -y mysql-client

mysql -h <内网地址> -P 3306 -u sijiguoxian -p sijiguoxian < /path/to/sijiguoxian/server/sql/schema.sql
```

---

## 3. 域名 + HTTPS（支付、小程序都要）

1. 腾讯云 → **域名注册** 买一个域名（或用已有域名）  
2. **DNS 解析** → 添加 A 记录：  
   - 主机记录：`api`（或 `@`）  
   - 记录值：CVM 公网 IP  
   - 例：`api.你的域名.com` → `1.2.3.4`  
3. **SSL 证书** → 申请免费证书（DV）→ 下载 Nginx 版  
4. 等解析生效（几分钟到几小时）

---

## 4. 服务器装环境 + 跑项目

SSH 登录：

```bash
ssh ubuntu@你的公网IP
# 或 root@你的公网IP
```

安装 Node / Nginx：

```bash
sudo apt update
sudo apt install -y nginx git
# Node 18
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs
node -v
```

上传代码（本机执行）：

```bash
# 在你电脑上
cd /home/wujie/work/sijiguoxian
rsync -avz --exclude node_modules --exclude server/data ./ ubuntu@公网IP:~/sijiguoxian/
```

或服务器上 `git clone`（需先把仓库推成功）。

服务器配置：

```bash
cd ~/sijiguoxian/server
cp .env.example .env
nano .env
```

`.env` 关键项示例：

```bash
PORT=3000
DB_DRIVER=mysql
MYSQL_HOST=你的MySQL内网地址
MYSQL_PORT=3306
MYSQL_USER=sijiguoxian
MYSQL_PASSWORD=数据库密码
MYSQL_DATABASE=sijiguoxian

PAY_MODE=wechat
WX_APPID=...
WX_SECRET=...
WX_MCH_ID=...
WX_API_KEY=...
WX_NOTIFY_URL=https://api.你的域名.com/api/pay/notify

CLOUD_PRINT_ENABLED=true
CLOUD_PRINT_PROVIDER=feie
CLOUD_PRINT_USER=...
CLOUD_PRINT_UKEY=...
CLOUD_PRINT_SN=...

JWT_SECRET=随机长字符串
ADMIN_PASS=强密码
```

安装依赖并启动：

```bash
npm install
# 用 pm2 守护
sudo npm i -g pm2
pm2 start src/index.js --name sijiguoxian
pm2 save
pm2 startup
```

## 5. Nginx 反代 HTTPS

证书文件放到例如 `/etc/nginx/ssl/`，新建站点：

```bash
sudo nano /etc/nginx/sites-available/sijiguoxian
```

内容：

```nginx
server {
    listen 80;
    server_name api.你的域名.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.你的域名.com;

    ssl_certificate     /etc/nginx/ssl/你的证书.crt;
    ssl_certificate_key /etc/nginx/ssl/你的证书.key;

    client_max_body_size 10m;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用：

```bash
sudo ln -s /etc/nginx/sites-available/sijiguoxian /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

浏览器打开：

- `https://api.你的域名.com/api/health` 应返回 `{"ok":true,...}`  
- `https://api.你的域名.com/admin/` 管理端登录

## 6. 配置微信后台

1. [微信公众平台](https://mp.weixin.qq.com/) → 开发 → 开发管理 → **服务器域名**  
   - request 合法域名：`https://api.你的域名.com`  
2. 小程序 `miniprogram/utils/config.js`：

```js
baseUrl: 'https://api.你的域名.com'
```

3. `project.config.json` 填真实 AppID  
4. 微信支付商户平台：绑定小程序、配好 APIv2 密钥，回调 URL 用上面的 `WX_NOTIFY_URL`

## 你卡在哪一步可以问我

常见卡点：

1. MySQL 连不上 → 多半 VPC/安全组没通  
2. 小程序 request 失败 → 域名没配白名单或不是 https  
3. 支付没回调 → `WX_NOTIFY_URL` 外网打不开或签名密钥错  

把 **公网 IP、域名、MySQL 内网地址**（密码私聊）发我，我可以按你的实际值写好一份最终 `.env` 和 Nginx 配置。
