# 食品经营许可办理要点（北京 · 海淀 · 果切/水果捞）

> 营业执照 ≠ 食品经营许可证。  
> 现执照经营范围以水果**零售**等一般项目为主；**现场洗切制售、水果捞**通常还要办食品经营许可。

## 一、要不要办

| 业态 | 是否通常需要食品经营许可 |
|------|--------------------------|
| 仅售未加工整果 / 预包装 | 多按食用农产品/食品销售管理，以当地窗口为准 |
| **现切果杯、拼盘** | **需要**（餐饮服务 · 冷食类食品制售，多为简单制售） |
| **水果捞（酸奶+鲜果）** | **需要**（冷食制售；酸奶须合格冷藏） |
| 清洗后分装「免洗小盒」 | 现场分装制售倾向需要许可；纯外购预包装另说 |

**建议：按「冷食类食品制售（简单制售）」一次办妥，避免只开零售证却做现切被查。**

## 二、办理依据（查阅用）

- 《食品经营许可管理办法》及北京市实施细则  
- 《北京市食品经营许可审查细则》（近年有修订，以海淀市场监管局窗口最新口径为准）  
- 线上入口：北京「一网通办」/ 海淀区市场监督管理局食品经营许可

## 三、材料与现场常见要求（果切店）

1. **营业执照**（已办：四季果先（北京）水果零售有限公司）  
2. **食品经营许可申请表**（主体类型：企业）  
3. **经营场所平面图** + 设备布局（建议按你们「玻璃封闭鲜切间 + 传递窗」方案，勿开放式后厨）  
4. **设施设备清单**：清洗消毒、冷藏冷冻、操作台、工器具等  
5. **食品安全管理制度**（进货查验、清洗消毒、人员健康、废弃物等）  
6. **从业人员健康证明**（接触直接入口食品）  
7. 法人/负责人身份证件  

现场核查常看：

- 专用操作区/专间界定是否清楚（到顶隔断更稳）  
- 入口洗手消毒干手（非手动龙头更佳）  
- 三槽或等效清洗消毒设施  
- 冷藏温度与原料分区（生熟、肉果分开若适用）  
- 无明火油烟要求时，勿擅自加烧烤类

## 四、许可项目勾选建议

与窗口确认后，优先勾选接近：

- 餐饮服务经营者  
- **冷食类食品制售**（简单制售）  
- 如有预包装销售，再按实际勾选食品销售相关项  

外卖递送、互联网销售可在执照一般项目已有基础上，按许可与备案要求补充（外卖平台入驻另要许可证号）。

## 五、和开业节奏的关系

| 阶段 | 建议 |
|------|------|
| 许可未下发前 | 可筹备装修、小程序、收款进件；**对外现切/水果捞销售建议等许可** |
| 仅卖整果零售 | 风险相对低，仍建议先问清窗口 |
| 计划开业 2026-10-16 | 尽快预约海淀窗口或网申，预留现场整改时间 |

## 六、办完后要做的

1. 亮证（店内公示食品经营许可证）  
2. 许可证号可用于外卖平台、检查应对  
3. 若住所/布局与申请不一致，先变更再营业  
4. 宣传文案避免无法举证的「零农残」绝对表述；可用「专业清洗、更放心」等

## 七、咨询

- 海淀区市场监督管理局食品经营许可窗口 / 12345  
- 携带平面图与执照原件问「冷食简单制售 · 鲜切水果」是否可按你们 22㎡ 方案审
