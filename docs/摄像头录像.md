## 原方案备忘（以后可开）

## 你要的效果

- 点 **开始制作** → 程序自动开始录像  
- 点 **待取/完成** → 程序自动停止并上传  
- 顾客小程序自动能看  
- **不需要** 再点「上传视频」  
- **不需要** 台式/笔记本常开  

## 怎么用（推荐）

用店员 **手机浏览器** 打开制作台：

```
http://你的服务器地址:3000/admin/make.html
```

或管理端左侧点 **「制作台（自动录像）」**。

流程：

1. 登录后允许摄像头权限，手机支架对准操作台（或手持俯拍）  
2. 勾选订单 → **开始制作（自动录像）**  
3. 切果  
4. **制作完成 · 待取（自动上传）**  
5. 顾客订单页即可「观看制作过程」  

手机挂个支架即可，这不是「配电脑」，只是店员日常用的手机。

## 为什么不能“零设备”全自动？

网络摄像头自己不会知道你点了「开始制作」，也不会自己把视频传到你的服务器。  
必须有一个会跑程序的东西：手机制作台，或迷你主机 + RTSP（可选）。

| 方案 | 设备 | 自动上传 |
|------|------|----------|
| **制作台网页（推荐）** | 手机 | ✅ 开始/待取即自动 |
| RTSP + recorder | 摄像头 + 迷你主机 | ✅ |
| 管理端手动上传 | 手机 | ❌ 要多点一次上传 |

## 可选：以后上 RTSP

若以后买了 ONVIF 摄像头并愿放一台迷你主机，可用 `recorder/` 目录的助手，见技术备忘。开店阶段用制作台即可。
