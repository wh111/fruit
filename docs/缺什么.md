# 四季果先 · 正式上线你需要提供什么

代码已按「正式」接好：MySQL 云库 + 微信支付 + 云打印。  
下面是**你还缺、需要准备/发给我**的清单。发齐后我可以帮你填进 `.env` 并验收。

---

## 一、云服务器 + 域名（必选，腾讯云或阿里云二选一）

| 缺什么 | 说明 | 你怎么拿到 |
|--------|------|------------|
| 云服务器 | 2核4G 即可，系统 Ubuntu 22 | 腾讯云 CVM / 阿里云 ECS |
| 公网 IP | 服务器外网 IP | 控制台可见 |
| 域名 | 如 `api.xxx.com` | 万网/腾讯云/阿里云买域名 |
| HTTPS 证书 | 支付回调必须 https | 云厂商免费 DV 证书 / Let’s Encrypt |
| 已解析到服务器 | A 记录指向公网 IP | 域名解析控制台 |

服务器上要能跑：`Node.js 18+`、Nginx（反代 HTTPS）。

---

## 二、云数据库 MySQL（必选）

| 缺什么 | 说明 |
|--------|------|
| MySQL 实例 | 腾讯云 CynosDB/TDSQL-C 或 阿里云 RDS MySQL 5.7/8.0 |
| 主机地址 | 如 `rm-xxx.mysql.rds.aliyuncs.com` 或腾讯云内网地址 |
| 端口 | 一般 `3306` |
| 库名 | 建议 `sijiguoxian` |
| 账号/密码 | 不要用 root 对外，建专用账号 |

建好后在库里执行一次项目里的：

`server/sql/schema.sql`

`.env` 里设：

```bash
DB_DRIVER=mysql
MYSQL_HOST=...
MYSQL_PORT=3306
MYSQL_USER=...
MYSQL_PASSWORD=...
MYSQL_DATABASE=sijiguoxian
```

并在服务器 `server` 目录执行：`npm install`（安装 mysql2）。

## 三、微信小程序 + 支付（必选）

| 缺什么 | 说明 |
|--------|------|
| 小程序 AppID | 微信公众平台 |
| 小程序 AppSecret | 同上 |
| 微信支付商户号 mch_id | 微信支付商户平台 |
| APIv2 密钥（32位） | 商户平台 → API 安全 |
| 小程序已关联商户号 | 商户平台绑定 AppID |
| 已开通 JSAPI 支付 | 商户平台产品中心 |
| 服务器域名已配白名单 | 小程序后台 → request 合法域名填你的 https 域名 |
| 支付回调 URL | `https://你的域名/api/pay/notify` |

`.env`：

```bash
PAY_MODE=wechat
WX_APPID=...
WX_SECRET=...
WX_MCH_ID=...
WX_API_KEY=...
WX_NOTIFY_URL=https://你的域名/api/pay/notify
```

小程序 `project.config.json` 的 `appid` 也要改成真实 AppID。

## 四、云打印机（强烈建议）

| 缺什么 | 飞鹅 | 易联云 |
|--------|------|--------|
| 打印机硬件 | Wi‑Fi/4G 云小票机，约 400–600 元 | 同价位 |
| 开放平台账号 | admin.feieyun.com | open.10ss.net |
| 凭证 | USER + UKEY + 打印机 SN | CLIENT_ID + SECRET + 终端号 |

`.env` 示例（飞鹅）：

```bash
CLOUD_PRINT_ENABLED=true
CLOUD_PRINT_PROVIDER=feie
CLOUD_PRINT_USER=...
CLOUD_PRINT_UKEY=...
CLOUD_PRINT_SN=...
```

（可选）再买一台 USB 标签机贴杯盖，管理端「打印标签」用。
