# 四季果先 · 贴纸打印硬件指南

支付成功后系统会生成：

- **取餐短码**：如 `A083`（店员口头核对也方便）
- **二维码**：内容为订单核销链接 / 订单号
- **标签内容**：品牌名、果切名称、规格、取餐码、二维码、下单时间

目标：打印成贴纸，贴在果杯盖或杯身。

---

## 方案一：门店电脑 + USB/网口标签机（推荐起步）

适合：有收银电脑 / 平板常开管理端的门店。

### 需要买什么

1. **热敏标签打印机**（任选其一）
   - 汉印 N31 / N41
   - 佳博 GP-3120TU / GP-1324D
   - 芯烨 XP-365B / XP-420B
2. **标签纸**
   - 尺寸建议：**40×30mm** 或 **50×30mm** 不干胶热敏纸
   - 有「防水/防油」涂层更好（果切湿气大）
3. **电脑**
   - 已安装打印机驱动
   - 浏览器打开管理端，点「打印标签」即可（走系统打印对话框）

### 优点

- 稳定、便宜、一单一点就能打  
- 管理端已做打印预览页，适配常见 40×30 / 50×30

### 操作

1. 安装驱动 → Windows「设备和打印机」能看到设备  
2. 管理端订单列表 →「打印标签」→ 选择该打印机  
3. 撕下贴纸贴在杯盖

---

## 方案二：德佟标签机 + 本机打印助手（已接入）

适合：你已购买 [德佟标签机 / dtpweb SDK](https://detonger.com/#/sdk/detail?sdkID=BD059F87-F6FE-447B-94F7-B371491BA6CE)。

德佟**不是**飞鹅那种云推送，而是电脑上的 **dtpweb 打印助手**。正确链路：

```
顾客小程序支付成功
  → 后端生成取餐码
  → 店里电脑打开管理端（勾选「新单自动打印」）
  → 管理端检测到新单
  → 调用本机 dtpweb → 德佟机出标签
```

### 需要准备

1. 德佟标签打印机（USB/蓝牙连到**店里那台电脑**）
2. 安装并保持运行 **dtpweb 打印助手**（德佟官网 SDK / 随机软件）
3. 标签纸尺寸与管理端一致（默认 **50×30mm**，也可改 40×30）
4. Chrome / Edge 打开管理端：`http://本机或服务器/admin/`

### 操作

1. 管理端 → **打印硬件** → 确认「已连接打印助手」→ 选择打印机 → **测试打印**
2. 右上角勾选 **「新单自动打印」**
3. 用小程序下一单并支付，店里应自动出标

代码位置：

- `admin/js/detong-print.js`（德佟绘制/打印）
- `admin/js/admin.js` 的 `printLabel`（优先德佟，失败回退浏览器打印）

### 订单标签自定义 + 批量条形码

管理端 → **打印硬件**：

1. **订单标签自定义**：品牌名、二维码/一维码、是否显示价格/预约时间等（保存在浏览器本地）
2. **批量生产条形码**：
   - **连号**：前缀 `SG` + 起始号 + 数量（如 SG0001～SG0010）
   - **手动列表**：每行 `条码,品名,价格,份数`
   - **从在售商品生成**：按商品规格批量出标

适合：杯贴预印、货架码、规格价签。仍需本机 dtpweb 打印助手。

---

### 注意

- 电脑休眠或关掉管理端页面，就不会自动打（可常开一台收银机/迷你主机）
- 若要「服务器直接推到打印机、电脑不用开网页」，需另购飞鹅/易联云云小票机

## 方案三：手机蓝牙标签机（店员走动贴杯）

适合：后厨/吧台移动贴标。

### 需要买什么

1. **蓝牙标签打印机**
   - 精臣 B21 / D11 / D30
   - 汉印小标侠系列
   - 喵码 / 商米标签机
2. **配套标签纸**（跟机型匹配，注意宽度）
3. **手机** 装厂商 App，或使用云打印开放接口

### 对接方式

- **简单**：管理端显示二维码/取餐码，店员用手机 App「扫内容打印」  
- **进阶**：对接厂商云打印 API（在 `server/.env` 配置），下单成功自动推送到蓝牙机（需厂家开放平台账号）

本项目默认优先「德佟本地打印」；也可用浏览器打印；云打印接口：`POST /api/print/cloud`。

---

## 方案四：小票机打二维码（临时替代）

若暂时没有标签机：

- 买一台 **58mm 热敏小票打印机**（美团外卖同款）
- 管理端「打印小票」会打出：店名 + 取餐码大号字体 + 二维码 + 品名规格  
- 用透明胶带贴在杯上也能用，正式营业再换成不干胶标签

## 推荐采购清单（开店一套）

| 物品 | 数量 | 说明 |
|------|------|------|
| 热敏标签打印机（USB） | 1 | 佳博/汉印/芯烨均可 |
| 40×30mm 热敏不干胶标签 | 2–5 卷 | 日销量大可多备 |
| 收银电脑或平板 | 1 | 打开管理端接单打印 |
| （可选）蓝牙标签机 | 1 | 后厨补打、临时档口 |

预算大约：**300–800 元** 即可跑通「支付 → 出码 → 贴杯」。

---

## 微信小程序能否直接连打印机？

- **不能**直接 USB 连店内打印机（小程序无 USB 权限）
- **可以**：
  1. 顾客端只负责下单支付展示码  
  2. **管理端 / 后厨屏**负责打印（本方案）  
  3. 或通过「云打印机」（飞鹅、易联云、芯烨云）HTTP 推送，小程序支付回调后自动出纸

若你后续要「支付成功自动出纸、不用人手点」，告诉我打印机品牌型号，可再加云打印对接。
